Dark Mode

Dark mode is driven by a single attribute, data-bs-theme="dark", set on <html> (or any ancestor). Every --ds-color-* custom property that components read directly is re-pointed to its dark value by _dark-mode.scss, generated from each color token's dark override in tokens/color.tokens.json. Toggle the switch below to preview it live, using the real published token values — not a standalone demo palette.
